# Assets Directory
This directory contains static assets such as audio files, sounds, and images used by the bot.

## Audio Assets

### `welcome.mp3`
- **Purpose**: Greeting audio played automatically when a member joins the "Welcome VC" (or configured welcome channel).
- **Script Reference**:
  > *"Welcome to Rounit's Discord. Read the guidelines, check the project showcase, and let's get building."*
- **Customization**:
  To use custom voiceover or TTS audio, replace `assets/welcome.mp3` with your recorded audio file (MP3 or WAV format). The bot automatically cleans up voice connections once playback finishes.
